AI Swing Trader - Mobile Paper Trading Prototype

Open index.html in a browser for local testing. For reliable iPhone Home Screen installation, host these four files together on an HTTPS static host such as GitHub Pages or Netlify. Open the HTTPS address in Safari, tap Share > Add to Home Screen.

This app is NOT deployed. No live NSE prices, AI model, automated alerts, or BoB eTrade connection are included. It is a rules-based research and virtual-trade dashboard. Import daily CSV with date,open,high,low,close,volume (ISO dates) for one stock and at least 80 rows. Do not treat signals as financial advice. No order is ever sent. Paper trades persist only in local browser storage and can be lost if browser data is cleared. No real-time portfolio mark-to-market: dashboard equity values holdings at cost. Backtest excludes costs, taxes and slippage. No account credentials needed.
